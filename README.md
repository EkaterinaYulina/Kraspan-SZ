# Краспан Северо-Запад: сайт

Структура сайта и кликабельный прототип.

- `prototype/index.html` — схематичный прототип (открывается в браузере, без сборки). Вкладка «Дерево сайта» показывает все страницы.

Платформа: Tilda (не согласовано окончательно).

## Структура после правок заказчика (22.10.2026)

- Главная
- Фасады: навесные фасадные системы, 10 страниц, в том числе «НФС с УФ-печатью «Поликолор»» (рабочее название)
- Металлокаркасы: 7 страниц
- Освещение FOS: 5 направлений (уличное, промышленное, для химически агрессивных сред, внутреннее, архитектурное)
- Объекты
- Контакты

Раздел «Облицовочные материалы» убран, облицовки живут внутри страниц систем.
